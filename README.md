# Portfolio

A personal portfolio site: a grid of project cards on the home page, each
opening into a full project page. Built with React, React Router,
TypeScript, and Tailwind CSS, via Vite.

## Running it locally

```bash
npm install
npm run dev
```

Then open the local URL Vite prints (usually `http://localhost:5173`).

To build a static, deployable version:

```bash
npm run build
```
